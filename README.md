# Appointment Booking Service

A small Spring Boot REST service that prevents a provider from being booked for overlapping active appointments, with conflict-safe booking and cancellation. Built as a bounded assessment slice — see [design-spec.md](design-spec.md) for the design rationale and [limitations.md](limitations.md) for what's intentionally not here.

## Prerequisites

- Java 17+
- Maven 3.8+ (no wrapper is included — uses the system `mvn`)

## Build & run

```bash
mvn spring-boot:run
```

Starts on `http://localhost:8080`. No configuration or database needed — the store is in-memory only (see [limitations.md](limitations.md)).

## API documentation

Once running, the API is browsable and testable via Swagger UI at [http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html), with the raw OpenAPI spec at [http://localhost:8080/v3/api-docs](http://localhost:8080/v3/api-docs). Auto-generated by springdoc-openapi from the existing `@RestController` — documentation only, not part of the required deliverables.

## Run the tests

All tests:

```bash
mvn test
```

Just the concurrency tests:

```bash
mvn test -Dtest="BookingServiceTest#book_concurrentAttemptsSameSlot_onlyOneSucceeds+cancelBookRace_repeatedly_alwaysReachesValidEndState+concurrentBookingSameNewSlot_repeatedly_exactlyOneSucceedsEveryIteration"
```

## Quick manual smoke check

Book an appointment:

```bash
curl -i -X POST http://localhost:8080/appointments \
  -H "Content-Type: application/json" \
  -d '{"providerId":"p1","customerId":"c1","startTime":"2026-11-01T10:00:00Z","endTime":"2026-11-01T11:00:00Z"}'
```

Cancel it (replace `<id>` with the `id` from the response above):

```bash
curl -i -X POST http://localhost:8080/appointments/<id>/cancel
```

A fuller set of ready-to-run requests (including the rejection cases) is in `thunder-collection.json` — import it into the Thunder Client VS Code extension for a quick manual walkthrough.
